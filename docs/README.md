# OctoAcme Project Management Docs

Welcome! This README is the central entry point for all OctoAcme project management process documentation. Use it to orient yourself quickly, understand how OctoAcme delivers projects, and navigate to the detailed process guides below.

---

## Overview

OctoAcme follows a structured, iterative project management approach built on four core principles:

- **Customer-first** — every decision prioritizes customer value and usability.
- **Iterative delivery** — work is delivered in small, testable increments to reduce risk and gather feedback early.
- **Clear ownership** — each project has a named Project Manager (PM) and Product Manager (PdM) accountable for delivery.
- **Data-informed decisions** — outcomes are measured and plans are adjusted based on evidence.

Projects move through five lifecycle stages: **Initiation → Planning → Execution → Release → Retrospective**. Each stage has documented processes, key artifacts, and defined roles to keep teams aligned and delivery predictable.

### Key Roles

| Role | Responsibility |
|------|---------------|
| Project Manager (PM) | Coordinates delivery, schedules, risk, and communications |
| Product Manager (PdM) | Defines outcomes, prioritizes the backlog, measures success |
| Developers | Implement features, contribute to design and testability |
| QA / Testing | Validates quality and acceptance criteria |
| Stakeholders | Provides inputs and approvals |
